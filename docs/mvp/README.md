# docs/mvp/

## Purpose
Everything needed to build and present the Hintwise MVP: the shared build contract, the live demo script and the pitch-deck content.

## Contents
| File | Description |
|---|---|
| [MVP_SPEC.md](./MVP_SPEC.md) | The contract for every agent building the MVP: layout, data model, REST API, gated-AI pipeline, seed data, frontend. |
| [DEMO_SCRIPT.md](./DEMO_SCRIPT.md) | 5–7 minute live demo for judges, beat by beat, with exact clicks, lines and chat inputs, plus Plan B (mock mode). |
| [PITCH_DECK.md](./PITCH_DECK.md) | 10-slide pitch deck content (bullets + speaker notes); statistics cite `docs/research/` reports. |

## Key decisions
- One story thread in the demo (Quillstone pricing): build guardrails → solve live → review the pre-baked session. The A/B case proves "any role".
- Deck statistics are only those already sourced in [`../research/`](../research/README.md).
- Demo content lives in [`/demo`](../../demo/README.md).
