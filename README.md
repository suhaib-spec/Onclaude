# AI-Assisted Coding Interview Trainer

Helps interviewees prepare for and practice **AI-assisted coding interviews** — interviews where candidates
are expected to solve problems while working alongside AI coding tools.

> 🤖 **AI agents:** read [AGENTS.md](./AGENTS.md) before doing anything.

## Purpose
This is the root of the documentation hierarchy. Every folder has its own `README.md`; start here and
follow the links down to any feature.

## Contents
| Path | Description |
|---|---|
| [AGENTS.md](./AGENTS.md) | Foundational rules for every AI agent and contributor. |
| [CLAUDE.md](./CLAUDE.md) | Pointer to `AGENTS.md` for Claude-based tools. |
| [TASKS.md](./TASKS.md) | Task tracker and log — every change, requested and done. |

_Feature folders will be listed here as tasks create them._

## Key decisions
- All work is driven by tasks logged in `TASKS.md`.
- Commits go directly to `main`, one per task, referencing the task ID.
